INSTAVAULT - Instagram Downloader

1. Create and activate a virtual environment (optional):
   python -m venv venv
   venv\Scripts\activate

2. Install:
   pip install -r requirements.txt

3. Run:
   python app.py

4. Open:
   http://127.0.0.1:5000

This app is intended for public Instagram Reel/Post URLs and content
you have permission to download.
